Under the hood

State-of-the-art models, running in your browser.

LLM

Phi-4-mini (3.8B) via web-llm + WebGPU. Llama-3.2-1B fallback for lower-end hardware.

Embeddings

bge-small-en-v1.5 (384-dim) via ONNX Runtime. Fast semantic understanding.

Reranker

ms-marco-MiniLM cross-encoder via ONNX. Precision re-scoring for retrieval.

Voice

Moonshine-tiny ASR + Silero VAD. Real-time transcription on-device.

Vector Store

Orama BM25 + brute-force cosine vector search, persisted in IndexedDB. Fused with RRF, then cross-encoder reranked.

Chunking

Semantic chunking via compromise.js NLP + embedding similarity boundaries.
