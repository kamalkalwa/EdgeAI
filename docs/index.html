Get started in 3 minutes

  1. Install the extension

    Add EdgeAI to Chrome. The AI model downloads once (~2.3GB) and is cached locally.

  2. Import your knowledge

    Connect your Obsidian vault, drop PDFs, import bookmarks, or click "Index this tab" on any web page.

  3. Ask anything

    Questions are answered from YOUR personal context — not generic training data. Type or speak.

  4. Verify it's private

    Open the Trust Panel. The network monitor shows zero external requests. The audit log shows every query — stored locally, never transmitted.
