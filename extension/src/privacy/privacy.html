Privacy Policy

EdgeAI — Private AI Assistant

TL;DR EdgeAI does not collect, transmit, or store any of your data on external servers. Everything runs locally on your device.

No Data Transmission

EdgeAI processes all AI inference (chat, search, embeddings, voice transcription) entirely on your device using WebGPU and WebAssembly. No data is sent to any external server, API, or cloud service during normal operation.

No Accounts or Telemetry

  • No user accounts or sign-up required
  • No analytics, telemetry, or crash reporting
  • No cookies or tracking pixels
  • No fingerprinting or device identification

Model Downloads

The only network requests EdgeAI makes are to download AI model files from Hugging Face CDN on first use. These files are cached locally via the browser's Cache API and are never re-downloaded unless the cache is cleared. You can verify this using the Network Activity Log in the Trust Panel.

Data Stored Locally

All user data is stored in your browser's local storage (IndexedDB and chrome.storage.local):

  • Documents and chunks: Text content you import (Obsidian vaults, PDFs, bookmarks, web pages) is chunked and stored with vector embeddings for retrieval
  • Chat history: Your conversations with the AI assistant
  • Settings: Your voice and display preferences
  • Audit log: A local record of all queries and operations (viewable in the Trust Panel)

Clearing Your Data

You can delete all EdgeAI data at any time by:

  • Removing individual documents from the Documents tab
  • Clearing chat history from the sessions panel
  • Clearing the audit log and network log from the Trust Panel
  • Uninstalling the extension (removes all data completely)

Permissions Explained

  • storage / unlimitedStorage: Store documents, embeddings, and model cache locally
  • offscreen: Run AI inference in a background document (required for WebGPU access)
  • activeTab / scripting: Extract page content when you use "Index this tab"
  • bookmarks: Import bookmarks for indexing (only when you explicitly choose to)
  • host_permissions (all URLs): Download AI models from Hugging Face CDN and extract content from any tab you choose to index
  • webRequest: Power the network activity monitor in the Trust Panel (read-only observation)
  • alarms / notifications: Support voice-initiated reminders
  • contextMenus: Add "Index this page with EdgeAI" to the right-click menu

Open Source

EdgeAI is fully open source. You can inspect every line of code, verify the build, and confirm that no data exfiltration occurs. The exact commit hash of the running build is shown in the Trust Panel.
